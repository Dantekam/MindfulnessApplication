# Mindfulness Application

A mobile mindfulness application developed with Flutter and Dart as a collaborative UNCW software development project.

The application was designed to provide users with an accessible mobile platform for mindfulness activities while exploring full-stack mobile development, persistent user data, and cloud-backed application functionality.

## Features

- Mobile mindfulness and wellness experience
- User account and authentication functionality
- Persistent user information
- Cloud-based data storage
- Real-time data communication
- Responsive Flutter user interface
- Multi-screen application navigation

## Technologies

- Flutter
- Dart
- Firebase
- Firebase Authentication
- Cloud Firestore
- Git / GitHub
- Android mobile development

## Firebase Integration

Firebase provides the application's backend services, allowing the Flutter client to communicate with cloud-hosted user data.

The project uses Firebase to support functionality such as user authentication and persistent application data, demonstrating integration between a mobile front end and a cloud-based backend.

## Project Structure

The application follows Flutter's widget-based development model, separating user interface components, application logic, and Firebase-backed functionality.

The project demonstrates experience with:

- Flutter UI and widget development
- Dart application logic
- Firebase integration
- User authentication
- Database operations
- Asynchronous application behavior
- Mobile application testing and debugging
- Collaborative software development

## Project Background

Developed as a collaborative UNCW competition project. This repository contains my preserved copy of the completed application for portfolio purposes.

Development was completed collaboratively, with both myself and my team member contributing across implementation, testing, debugging, and review rather than maintaining strictly separated areas of ownership.
